[前回の記事](/posts/gemini-omni-japan-launch/) では Google I/O 2026 の **Gemini Omni** が日本でも展開された話を整理しました。今回は同じ I/O で発表された **Google 検索 / AI Mode のアップデート** を抜き出します。

Google 公式が **「過去25年で最大の検索改修」** と謳っているのが今回の話で、要は **「検索ボックスに何を入れていいか」も「検索が返してくる形」も丸ごと変わる** という発表でした。日本ユーザー目線で、今日から変わるところと、米国先行でまだ来ないところに分けて見ていきます。 😊

## 30秒で：何が変わったのか

ざっくり要点だけ先に置きます。

- **AI Mode のデフォルトモデルが Gemini 3.5 Flash に切り替わった**。推論を保ったまま **4倍速い応答**。今日からグローバル展開（日本含む）
- **検索ボックスに動画・画像・ファイル・Chrome のタブを直接放り込める** ようになった。テキスト以外の素材を「並べて」検索する世界へ
- **AI Overviews と AI Mode が一体化** — 概要が出た流れのまま深掘り対話に進める
- 質問に応じて検索結果が **その場で UI として組み上がる**（Antigravity 連携、カスタム・ジェネレーティブ UI）
- **Information Agents**（24時間バックグラウンド監視エージェント）が登場、ただし **米国の Pro / Ultra から先行**
- 結婚式の計画や引っ越し管理を **ミニアプリ化** する機能、米国先行で今後数か月

要するに、**「検索＝青いリンクが10件」のページが、ユーザーごとに別物の UI に化ける** 方向に進みます。 😎

## 今日から日本でも変わるもの

ここはグローバル展開、つまり日本も含む扱いの機能です。

### 1. AI Mode が圧倒的に速くなる

AI Mode のデフォルトが **Gemini 3.5 Flash** に変わり、他のフロンティアモデルと比べて **4倍の応答速度** を維持しながら推論力をキープ、と発表されました。

日常的に AI Mode を使っている人なら、待ち時間がそのまま体感で減るタイプの変更です。 😄

### 2. 新しい検索ボックス：テキスト以外も入れていい

これが一番大きな見た目の変化です。検索ボックスに次のものをまとめて入れられるようになりました。

- **画像**
- **ファイル**（PDF など）
- **動画**
- **Chrome のタブ**（開いているページ）

しかも個別に処理されるのではなく、**入れたもの全部を AI が同時に見て横断的に推論** します。

例えば「この PDF（仕様書）と、この YouTube 動画（解説）と、いま開いてる比較記事のタブ、ぜんぶ踏まえて判断して」が一発でできる構図です。 🤔

これは AI Mode が使えるすべての国と地域・言語で **本日（2026年5月20日）から展開開始**。日本も入っています。

### 3. AI Overviews → AI Mode のシームレス化

これまで「AI Overviews（検索結果の上の AI 概要）」と「AI Mode（対話モード）」は別物として動いていました。今回のアップデートで両者が統合され、

- 質問する
- 概要が出る
- そのまま「もっと詳しく」と対話に入る

の流れが **文脈を切らずに繋がる** ようになりました。検索結果ページを毎回開き直す動きが消えます。 😌

### 4. ジェネレーティブ UI（今夏、無料）

Google Antigravity のコーディング機能を Search に組み込み、**質問に応じて検索結果の UI そのものを動的に生成する** という機能。

発表で見せられたデモは「**ジャイロイド構造**（化学・建築界隈で出てくる複雑な3次元パターン）の解説」で、リンクの羅列ではなく **インタラクティブに回せる3D ビジュアル＋表＋シミュレーション** が検索ページに直接生成される、というもの。

これは **今夏に全ユーザー無料で提供開始** とされていて、日本も含む見込みです。 🥳

## 日本ではまだ使えないもの（米国先行）

ここからは「I/O で発表された ≠ 日本で今日使える」の罠ゾーンです。 😩

### Information Agents（24時間監視エージェント）

ブログ、ニュース、SNS、リアルタイムの金融・ショッピング・スポーツデータを **バックグラウンドで継続監視** して、ユーザーが気にしている話題に動きがあれば要約と通知を返す機能。場合によっては **代わりに行動** までする。

- 展開時期：**今夏**
- 対象：**Google AI Pro / Ultra のサブスクリプションユーザー**
- 地域：当面サブスク先行＝米国中心。日本での開始時期は発表されていません

デモで紹介されていた使い方：

- **アパート探し**：希望条件をエージェントに渡しておくと、条件に合う物件が出た瞬間に通知
- **スニーカードロップ通知**：好きなアスリートのコラボ新作が発売された瞬間に通知

### エージェントによる電話・予約

カラオケの予約、住宅修理、美容、ペットケアなど、**特定カテゴリの店舗に AI が代わりに電話を入れて、確認や予約を入れてくれる** 機能。

- 展開時期：**今夏**
- 地域：**米国から開始**
- 日本展開時期は未発表

「店に電話するのが面倒で先延ばしにしている用事」が AI に投げられる、という生活実感に直結するやつです。日本上陸を待ちたい層は多そう。 🥲

### ミニアプリ（Dashboards / Trackers）

検索結果から **継続的に使えるダッシュボード／トラッカー** を組み立てる機能。発表されていた具体例：

- 結婚式の計画ダッシュボード
- 引っ越しの進行管理トラッカー
- 地域の天気・地図・レビューを取り込んだ **カスタム・フィットネス・トラッカー**

- 展開時期：**今後数か月以内**
- 地域：**米国の Pro / Ultra** から開始
- 日本での開始時期は未発表

これは「**検索結果に住み続けるアプリを建てる**」という発想で、画面の意味合いが完全に変わる機能です。

## モバイル特有のアップデート

PC とモバイルで共通の変更（新検索ボックス、シームレス AI Mode）に加えて、**モバイル限定** で次の機能が入ります。

### Chrome for Android × Gemini 統合

Android 版 Chrome に Gemini が直接統合され、

- 閲覧中の長い記事を **その場で要約**
- ページの内容について **質問**
- 結果を **Google Keep やカレンダーに直接送る**

までがブラウザの中で完結します。 😄

### Auto Browse（Android）

これは少し攻めた機能。**チケット情報から駐車場の予約まで自動でやる**、といったレベルで、**ブラウザ作業を AI が代行** します。

- Android 上で動作
- 展開時期は段階的（詳細未発表）

「予約系の事務作業を AI に外注する」発想は、Information Agents と並んで I/O 全体の隠れたテーマだったように見えます。 🤗

## 開発者・高度ユーザー向け

ここは前述の機能と切り分けて見たほうがいい部分です。

- **Google Antigravity**：エージェント指向の開発プラットフォーム。検索の中で UI を動的に組み立てる仕組みは、ここの **マルチエージェント・オーケストレーション** が背骨になっている
- **検索内ミニアプリ構築**：上述の Dashboards / Trackers は、開発者側からも構築可能
- **Information Agents の早期アクセス**：サブスク条件あり

要するに、**「AI 検索を消費する人」と「AI 検索の中に住む小さなアプリを開発する人」の境目が一気に薄くなる** という構図です。

## まとめ：日本ユーザーが今日体感できる変化

今回の I/O で日本の検索体験が **今日から** 変わるところを抜き出すと、次の3点です。

1. **AI Mode が約4倍速くなる**（Gemini 3.5 Flash 化）
2. **検索ボックスに動画・画像・ファイル・Chrome タブを放り込める**ようになる
3. **AI Overviews と AI Mode がシームレスに繋がる**

ここまでは「今日から日本でも」。逆に、次の機能は **米国先行で日本ユーザーは待つ側** です。

- **Information Agents**（24時間監視エージェント）
- **AI による電話予約**（カラオケ・住宅修理・美容・ペットケア）
- **検索結果のミニアプリ化**（ダッシュボード／トラッカー）

そして **今夏には全ユーザー無料で** ジェネレーティブ UI が来る予定なので、夏以降に **検索ページの見た目そのものが質問ごとに別物** になる体験は、日本でも触れることになります。

I/O のキャッチでは「Agentic Gemini Era」と表現されていましたが、検索領域でその意味するところは、**「答える検索」から「動く検索」への移行** ということに尽きます。「青いリンクが10件」のページが、毎回ユーザー専用の小さな UI に置き換わっていく未来。検索体験がここまで根こそぎ作り変えられるアップデートは、確かに25年来ない規模だな、というのが正直な感想です。 😌

とりあえず明日の検索で **動画やタブを放り込んでみる** ところから、I/O 2026 の検索改修を体感できます。米国先行のエージェント機能が日本に来る日は、また別途追います。 😔
