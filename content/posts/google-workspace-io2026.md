[Gemini Omni 日本導入記事](/posts/gemini-omni-japan-launch/) と [Google 検索 / AI Mode 記事](/posts/google-search-ai-mode-io2026/) で I/O 2026 の大物トピックを2本書きました。今回は Google Workspace まわりに絞ります。

Workspace のアップデートは派手な発表に隠れがちですが、「仕事を始める入口」が変わる話なので、日常で効くインパクトはむしろ大きい部類です。 😊

## 30秒で：Workspace に入った変化

I/O 2026 で発表された Workspace の主要アップデートは3つに集約できます。

- Docs Live：音声で「いま頭の中にあること」を喋ると、Gemini が文書の構成とドラフトを書き上げる
- Google Pics：画像生成・編集ツール。生成済みの絵からオブジェクトを個別に選択して色変え・翻訳ができる
- Workspace 全体：Gemini が「呼び出して使うアシスタント」から「常に横にいる協働相手」に進化

要するに「白紙のドキュメントを開いて手で書き始める」前提自体が変わります。 😎

## 1. Docs Live：白紙のドキュメントが消える

Docs Live は今回のアップデートで一番生活感が変わる機能です。

使い方はシンプルで、Doc を開いて音声で「いま頭の中にあること」をそのまま喋るだけ。Gemini がそれを拾って、

- 文書の構成（見出し、段落分け）を考える
- 各セクションのドラフトを書く
- 必要に応じて表・箇条書きに整形する

までを代行します。 🤔

### 使うのが効きそうなシーン

- 朝の頭の中にあるアイデアを録音感覚で Doc にしてしまう
- 議事録：会議中の発言を流し込むと、構造化された議事録ドラフトが出る
- 提案書：「言いたいこと」を口頭で並べると、提案書テンプレに落とし込まれる

「Doc を開いて、何から書こうか…」と固まる時間が消えるタイプの機能です。

### 何が新しいのか

これまでも Gemini に文章を書かせることはできましたが、Docs Live の違いは

- 音声入力前提（タイピングが要らない）
- ドラフトではなく構成から組む
- Doc の中でそのまま完結する（外部に貼り付けない）

の3点です。「会話 → 文書」のレイテンシがほぼゼロになる方向に進んでいます。 😄

## 2. Google Pics：画像の中身を「触れる」

Google Pics は画像生成・編集ツールですが、今回 Gemini のマルチモーダル能力が反映されたことで「触れる粒度」が一段細かくなりました。

これまで AI 画像編集は「全体を変える（スタイル変換）」「部分を消す（インペイント）」の2方向が中心でしたが、Google Pics では生成済みの絵から、

- オブジェクトを個別に選択して色を変える
- オブジェクトに含まれる文字を翻訳する
- オブジェクト単位で形状を少しだけ変える

といった操作ができます。 🥳

### 使うのが効きそうなシーン

- 商品画像のラベル文字だけ別言語に翻訳して、海外向け広告素材を一気に量産
- イラストの服の色だけ変えて、季節違いのバリエーション展開
- スライド資料のアイコン色を一括変更

写真や生成画像が「平面のピクセル群」ではなく「オブジェクトの集合」として扱われ始める意味は地味に大きいです。

## 3. Workspace 全体：常時横にいる Gemini

Docs と Pics 以外にも、Workspace 全体で Gemini の存在感が変わっています。直接の I/O 発表項目ではないものの、流れとして押さえておきたい部分です。

- Gmail：返信ドラフト、要約、検索の AI 化
- Calendar：予定の自動調整、コンテキストに基づくリマインド
- Sheets：自然言語からの数式・グラフ生成
- Slides：プレゼン構成の AI 提案

これらは段階的に展開中で、I/O 2026 を境に「アシスタントを呼び出して使う」から「常時 Gemini が横にいる」感覚に切り替わる狙いです。 😌

## 日本展開：Workspace 系はグローバル傾向

検索や Information Agents のように「米国先行」の機能と違い、Workspace 系のアップデートは比較的グローバルロールアウト寄りです。

- Docs Live：段階的に Workspace ユーザーへ展開
- Google Pics：Gemini 統合機能としてグローバル展開予定
- Workspace 全体の Gemini 統合：すでに日本でも一部利用可能

ただし機能の細部や上位プラン限定の項目もあるので、Google Workspace 管理者ダッシュボードでオプトイン状況を確認するのが安全です。 😏

## まとめ：Workspace で今日試せる1つ

Workspace アップデートで「今日試す」価値が一番大きいのは Docs Live です。

1. Google Docs を開く
2. Gemini パネルから音声入力モードを起動
3. 5分間「今書こうとしている記事 / 議事録 / 提案書」のアイデアを喋り続ける
4. 生成された構成とドラフトを土台に手で仕上げる

タイピングよりはるかに速く下書きが出るので、白紙の前で固まる時間がほぼ消えます。 🤗

検索が「答える」から「動く」になり、Workspace が「待つ」から「先回りする」になる。I/O 2026 の主要メッセージである Agentic Gemini Era は、Workspace では「白紙の前に立った瞬間、Doc がもう構成案を出している」という形で体感できます。 😔
